## 2. 前提与局限
- 仓库无任何代码，所有实现可行性为设计推断；ACP 各智能体启动参数、微信限额、iOS 推送等以任务实测为准。
- 任务卡由 3 路分析师并行起草后经主规划者统一修正冻结字段；卡内个别“权宜方案”描述早于 CR-001，**以 ADR-015 与契约为准**。
- 工期未承诺（U-08），关键路径 22 个理想人日仅表示最短串行链长度。
- 规划未经独立验证者复核；建议 S0 启动前由 opus 档做一次契约审（已计入 S0 券）。
