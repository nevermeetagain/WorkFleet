# WorkFleet 产品路线图

> 规则（DEC-045）：第二版及以后每个产品版本要加、要改的功能都记在本文件；每个文档版本（docs/WorkFleet-V0.0.x/）延续并更新本文件，变更写入文末“变更记录”，旧条目不删，改标 moved / cancelled / superseded。
> 产品版本（第一版 v1、第二版 v2……）与文档版本（V0.0.x）是两套编号。
> 来源标注：**【用户】**= 用户明确要求；**【规划】**= 规划者建议，可调整；**【待定】**= 依赖未裁定问题。
> V0.0.4 起，v1 每一行对应到正式需求 ID（`02_requirements/`），交付顺序见 `milestones.md`（M0…M10 ↔ S0…S10）。
