## 3. 券制度
- opus 每切片 ≤3 次（切片前契约审 / 卡住升级 / 高风险 review）。S2 有 4 张 opus 执行卡（041/042/044/045）：**超出 1 张，需用户批准**；替代方案：045 改为 sonnect 执行 + opus review（占 1 券）。默认采用替代方案，用户批准后可恢复。
- S8 有 4 张 opus 卡（161/163/164 执行 + 契约审）= 4：同样需批准；默认 164 改为 sonnect 执行 + opus review。
- fable 每切片 ≤1 次，仅在需要动需求或已冻结契约时启用；v1 预算 0。
- 超出需人批准。

## 4. 熔断
同一任务连续 2 次验收失败 → 停止改代码 → 重写任务书 / 升级档位 / 标记 blocked。禁止换提示词硬撞第 3 次。
