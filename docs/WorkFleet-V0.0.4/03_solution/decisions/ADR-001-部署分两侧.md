# ADR-001：部署分两侧：本机节点 + 云中转

## 1. Context
DEC-002/016/022/030 写于单机网关时期；DEC-037 引入云中转，DEC-047 引入多角色控制台，二者冲突。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 单机网关（所有 IM 连接在用户电脑）；B 本机节点 + 云中转（IM 在中转，智能体在本机）；C 全部上云（智能体也在服务器）

## 4. Decision
选 B。

## 5. Rationale
A 无法服务老板/部门等不在用户电脑前的接收人，且电脑休眠即全断；C 违反“代码与模型 Key 不出本机”（DEC-044）。B 满足 DEC-037/040/044/047/048。

## 6. Consequences
### Positive
+ 多人、多设备、离线排队成为可能；+ 公司可自建中转（DEC-048）。
### Negative
− 中转可见 IM 明文；− 多一跳延迟（香港，跨境）；− 需节点通道协议（ADR-005）。
### Risks
中转被攻破即泄露 IM 历史 → 强制 TLS、最小权限、审计、公司自建。
