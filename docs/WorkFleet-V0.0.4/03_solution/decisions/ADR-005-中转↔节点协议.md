# ADR-005：中转 ↔ 节点协议：WSS + JSON envelope + 每方向单调 seq + 累积 ack + 断线续传

## 1. Context
跨境链路（DEC-040），必须容忍断线、重复、乱序。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 自定义 WSS envelope；B gRPC 双向流；C MQTT

## 4. Decision
选 A。

## 5. Rationale
A 只需 443、穿透公司代理最容易、浏览器同栈可复用；B 需 HTTP/2 端到端，部分代理不支持；C 需额外 broker。

## 6. Consequences
### Positive
+ 至少一次 + 幂等键 = 实际“恰好一次”效果。
### Negative
− 需自写续传。
### Risks
帧上限 1 MiB，附件走 HTTPS 分片上传；心跳 20 s，60 s 无帧判定断线。
