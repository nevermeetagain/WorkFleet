# ADR-006：鉴权与权限：Web 用 HttpOnly 会话 Cookie；节点用配对码换设备令牌；RBAC 三角色 + 项目范围

## 1. Context
DEC-047 多角色；DEC-030 安全默认。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 会话 Cookie + 设备令牌；B 全 JWT；C OAuth 第三方登录

## 4. Decision
选 A；第三方登录进 backlog。

## 5. Rationale
A 可即时吊销；JWT 难吊销且易被放进 localStorage。设备令牌 256 bit 随机、库内只存 SHA-256。

## 6. Consequences
### Positive
+ 吊销即时生效。
### Negative
− 中转需存会话表。
### Risks
越权：所有 API 由 `tenancy.assertPermission` 统一拦截，Identity 契约列出禁止路径。
