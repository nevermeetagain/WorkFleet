# ADR-002：契约唯一源 = JSON Schema（2020-12），API 用 OpenAPI 3.1 引用

## 1. Context
规划指令 §4.2 要求唯一源、机器可校验、可生成契约测试；DEC-028 已定 JSON Schema。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A JSON Schema + OpenAPI 3.1（$ref 指向 schema 文件）；B zod 作源；C TypeScript 类型作源

## 4. Decision
选 A。

## 5. Rationale
A 与语言无关、可直接给 ajv 运行时校验、可生成 TS 类型（json-schema-to-typescript）与契约测试；B/C 绑定 TS 运行时，非 TS 客户端（未来移动端/第三方）难复用。OpenAPI 3.1 原生兼容 JSON Schema 2020-12，不构成第二个源（只做端点编目）。

## 6. Consequences
### Positive
+ 前后端/节点三方同源；+ CI 可校验示例。
### Negative
− 写 schema 比写 TS 啰嗦。
### Risks
生成物漂移 → CI 检查 `pnpm contracts:gen && git diff --exit-code`。
