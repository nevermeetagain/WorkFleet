# ADR-008：前端：React 19 + Vite + TanStack Query + Zustand + Radix/shadcn + Tailwind 4；一份 SPA 两个构建目标；PWA

## 1. Context
DEC-010 Schema 驱动表单；DEC-056/057 Web 对话与 PWA。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A React 生态；B Vue 3；C Svelte

## 4. Decision
选 A。

## 5. Rationale
参考项目 PC/OR 均为 React 19 + Radix（`40-综合/02`），可借鉴组件与模式；表单用 `@rjsf`（Apache-2.0）按适配器 JSON Schema 渲染。

## 6. Consequences
### Positive
+ 复用度最高。
### Negative
− 包体积需控制（预算见 DESIGN-010）。
### Risks
—
