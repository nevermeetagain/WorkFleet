# ADR-003：存储：中转与节点均用 SQLite（WAL，单写者）

## 1. Context
中转规模：两人共用 + 公司自建（≤ 数百用户量级，推断）；节点为单用户。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 两侧 SQLite；B 中转 PostgreSQL、节点 SQLite；C 两侧 PostgreSQL

## 4. Decision
选 A，并定义迁移触发条件。

## 5. Rationale
A 零运维、单文件备份、与 DEC-004 一致；B 在多实例 HA 前收益有限；C 对个人电脑过重。Kysely 方言抽象保留 B 的迁移路径。

## 6. Consequences
### Positive
+ 部署一条命令；+ 测试快。
### Negative
− 中转单实例，无水平扩展。
### Risks
触发 B 的条件（任一）：中转需多实例；写入 p95 > 50 ms 持续 1 天；单库 > 20 GB。
