# ADR-013：总控的模型调用：自写薄客户端（OpenAI 兼容 + Anthropic Messages），规则把关兜底

## 1. Context
DEC-043/044：用户自管模型；超限降级为规则把关。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 自写薄客户端；B 引入 LangChain；C 只支持 OpenAI 兼容

## 4. Decision
选 A。

## 5. Rationale
总控只需 chat + 工具调用 + 流式 + usage 统计；B 依赖面过大；C 排除 Anthropic 原生接口。

## 6. Consequences
### Positive
+ 依赖少、usage 精确。
### Negative
− 新提供方需加适配。
### Risks
费用估算 = 返回 usage × 用户填写单价（部分确认）。

## 7. Status
accepted（2026-10-17）。推翻需新 ADR，并把本文改为 superseded。
