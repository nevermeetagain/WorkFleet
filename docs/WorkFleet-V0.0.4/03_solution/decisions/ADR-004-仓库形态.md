# ADR-004：仓库形态：pnpm workspaces Monorepo + Makefile 统一入口，Node 22 LTS，TypeScript 5（strict）

## 1. Context
PROJECT-STRUCTURE-SPEC §7 根结构；DEC-032 TS/Node。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A pnpm workspaces + Makefile；B Nx；C Turborepo

## 4. Decision
选 A。

## 5. Rationale
三个应用 + 两个包，A 足够；B/C 增加学习与配置面，收益在更大规模才显现（spec §21 阶段 2）。模块边界由 dependency-cruiser 守卫，不依赖 Nx 标签。

## 6. Consequences
### Positive
+ 简单。
### Negative
− 无远程缓存。
### Risks
构建变慢时再引入 Turborepo（可逆）。

## 7. Status
accepted（2026-10-17）。推翻需新 ADR，并把本文改为 superseded。
