# ADR-012：全局命名与格式

## 1. Context
规划指令 §4.2：字段命名、时间、金额、枚举全项目统一。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
—

## 4. Decision
ID = 类型前缀 + ULID（`usr_`、`ten_`、`dev_`、`prj_`、`agt_`、`chn_`、`rcp_`、`rte_`、`cnv_`、`msg_`、`dlv_`、`apr_`、`bar_`、`aud_`、`mtg_`、`mdl_`、`twn_`）；JSON 字段 camelCase；DB 列 snake_case；时间：API 用 RFC 3339 UTC 毫秒（`2026-10-17T10:00:00.000Z`），DB 用 INTEGER 毫秒；金额：整数“微单位”`amountMicros` + ISO 4217 `currency`；枚举小写下划线。
