# ADR-009：后端运行栈：Fastify 5 + ws + better-sqlite3 + Kysely + pino + ajv

## 1. Context
DEC-032；需要三平台预编译、可测、低依赖。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A Fastify + better-sqlite3；B NestJS + TypeORM；C Express + node:sqlite

## 4. Decision
选 A。

## 5. Rationale
B 重框架、ORM 与 spec“ORM 只在 infrastructure”可兼容但样板多；C node:sqlite 在 Node 22 仍标实验（证据不足，需实测），Express 无内建 schema 校验。better-sqlite3 有三平台预编译包。

## 6. Consequences
### Positive
+ 轻、快、schema 原生。
### Negative
− 同步 SQLite 调用需控制在 worker 内或保持短事务。
### Risks
长查询（FTS）放 worker_threads。
