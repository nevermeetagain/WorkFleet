# ADR-007：输入端：通用 ACP 适配器 + ACP Registry + 本地 InputAdapterSpec 表；非 ACP 用专用适配器

## 1. Context
DEC-055 要求接入所有主流 ACP 智能体；DEC-007 表驱动。

## 2. Problem
需要一个可执行、可验证、可逆的选择，供并行开发 CLI 共同遵守。

## 3. Options
A 通用适配器 + spec 表；B 每个智能体一套代码；C 只支持 Registry 中的智能体

## 4. Decision
选 A。

## 5. Rationale
官方列表 40+ 智能体（agentclientprotocol.com/overview/agents，2026-10-17 读取）走同一 ACP 协议，差异集中在启动命令、认证与方言；B 线性增长维护量；C 无法覆盖 ZCode 等非 Registry 项。

## 6. Consequences
### Positive
+ 新增智能体 = 一条 spec + 一个录制夹具。
### Negative
− 方言差异需 `dialect` 钩子。
### Risks
Copilot ACP 为 public preview（官方），ZCode 为社区桥 → 标注实验。TS SDK 包名与版本在 TASK-021 实测确认（证据不足）。
