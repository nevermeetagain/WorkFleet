# WorkFleet 大白话使用说明（V0.0.3 设计态，产品尚未实现）

> 依据：DEC-032…039。凡标“规划中”的功能尚未裁定实现时机；标“待验证”的依赖未实测的事实。

## 一句话
手机上只留一个微信（或飞书）机器人，就能同时指挥电脑里的 Claude Code、Codex、Cursor、ZCode、OpenClaw 等所有工具；以后不用再“绑这个、解那个”。

## 它由三块组成
1. **云中转**（一台云服务器，暂定你俩共用、按账号隔离）：替你挂着微信机器人、飞书机器人，24 小时收发消息。
2. **本机节点**（装在每个人自己的电脑上）：负责拉起和驱动你的开发工具。代码和工具凭据不离开你的电脑；它主动连到云中转，家里不用开端口。
3. **手机**：微信或飞书，就是你的遥控器。

消息怎么走：手机 → 云中转 → 你的电脑 → 某个工具；工具的回复原路返回。电脑关机时，中转会告诉你“设备离线”。

## 第一次怎么装（以你为例：微信 + 本机工具）
1. 在云服务器上部署中转（一次性；朋友用同一台，只需你给他开个账号）。
2. 在自己电脑上装本机节点，登录你的中转账号。
3. 在控制台点“绑定微信”，**用手机微信扫一次码**。以后不再扫。
4. 控制台里勾选要接入的工具：Claude Code、Codex、Cursor、ZCode……本机节点会自动发现并连上它们。各工具里**不用扫码**。
5. 把各工具自带的“微信机器人”功能关掉（比如 ZCode 的 Bot Channel），否则会和 WorkFleet 抢同一个微信授权，谁最后扫谁生效（待验证）。

## 朋友怎么装（飞书 + 别的智能体）
1. 在飞书开放平台建一个**属于 WorkFleet 自己的**企业自建应用，把凭据填进控制台。
2. 他电脑上的 OpenClaw 通过 `openclaw acp` 接进本机节点。
3. OpenClaw 原来那个飞书机器人可以继续留着，但**不要和 WorkFleet 共用同一个飞书应用**——同一应用连两个程序，飞书会把消息随机只发给其中一个（已确认）。

## 能做什么：四种模式
在控制台里，用“谁（工具）→ 发到哪（聊天）”连线就行。
- **管理模式（多对一）**：所有工具都汇到一个微信聊天。消息前面带上 `[项目/工具]` 标签，你回复时用 `@codex 修一下登录页` 指定发给谁，不指定就发给上一个和你说话的工具。场景 1（三个项目六个工具，微信统一收）就是这个。
- **通知模式（一对多）**：一个来源发给多个接收方，比如日报同时发给“数据分析群”和“老板”。接收方也能回话。
- **团队模式（多对多）**：按项目或产品线分流。比如产品线 A 的开发、监控、报表全进微信，产品线 B 进另一个渠道，公司审批进飞书。MVP 只有微信和飞书；QQ、钉钉、Telegram、Discord 排在后面。
- **总控模式（规划中）**：在团队模式上加一个“职业经理人”智能体，跑在你自己的电脑上。你提一个需求，它先组织各工具“开会”分析，再拆任务、分给一个或多个工具；工具的输出都先过它，小事它自己回，大事、要花钱、要拍板的才找你。随时可以和它聊，不打断正在做的活。模型和技能可以自定义。

## 手机上常用的指令（规划，可能会调整）
- `/list`：看有哪些工具在线、各自在干什么
- `/use claude`：把后面的消息默认发给 Claude Code
- `/clear`：给当前工具开一个新对话
- `/history <会话ID>`：按会话 ID 查聊天记录
- `/stop`：停止当前任务
- 工具要执行危险操作（删文件、跑高权限命令）时，会发来确认，你回“同意”或“拒绝”

## 拓展功能（有更好，不是第一批）
- **定时任务**：像手机闹钟一样，一次、每天、工作日、休息日、每周、每月。例：每天 9:00 让某个工具整理 AI 新闻，推送给订阅的人。
- **对话记录**：两端记录都能按会话 ID 查。
- **知识库**：存项目设计、目录结构图谱、上下文记忆，供各工具和总控共用。
- **分身数据**：自动学习你的回复习惯，逐步让总控替你回更多小事（采集范围待定，Q-14）。

## 四个场景怎么配
1. **三个项目、六个工具、微信统一收**：管理模式，6 个工具 → 1 个微信聊天，按项目打标签。
2. **飞书数据管理**：通知或团队模式，推广、运营、销售汇总三个分析工具 → “数据分析部”群和“老板”两个接收方。
3. **主项目加子项目统一开发**：总控模式，经理人统一拆任务、统一汇报。
4. **每天 9 点给大量订阅用户推 AI 新闻**：定时任务加通知模式。注意：微信机器人是“个人号”性质，每个订阅者得先自己扫码加上机器人；用户量大的话，更适合飞书群推送或公众号类渠道（规模上限待定，Q-10）。

## 目前做不到 / 还没定的
- 同一个微信不能同时给 WorkFleet 和别的工具用（平台限制，不是我们选的）。
- 电脑关机时，本机工具没法干活，只能排队等。
- 中转能看到消息明文（IM 平台推过来就是明文），所以共用中转的人要互相信任。
- 还没定的：docs 组织（Q-07）、总控上线时机与预算（Q-08）、场景 4 的规模（Q-10）、场景 2 是否真有多人公司使用（Q-12）、分身数据范围（Q-14）、执行 Agent 分档（Q-15）、设备是否在大陆（Q-04）。
